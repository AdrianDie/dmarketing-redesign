# Prosjektregler for gemma_coder

Disse reglene gjelder for alle oppgaver i dette prosjektet.

## Generelt
- Svar alltid på norsk
- Aldri fjern eksisterende funksjonalitet uten eksplisitt tillatelse
- Foretrekk presise endringer (edit_file) fremfor å overskrive hele filer

## Kode
- Ikke legg til kommentarer som forklarer hva koden gjør — kun HVORFOR (ikke-åpenbare valg)
- Ikke legg til feilhåndtering for situasjoner som ikke kan oppstå
- Ikke legg til funksjoner brukeren ikke ba om

## Stil
- Følg eksisterende kodestil i prosjektet
- Ikke reformater kode du ikke endrer

## Sikkerhet
- Aldri hardkod passord, nøkler eller hemmeligheter
- Aldri kjør destruktive kommandoer (rm -rf, git reset --hard, etc.) uten eksplisitt bekreftelse
