2. Hvilke opplysninger vi samler inn

Vi samler inn følgende opplysninger når du bruker kontaktskjemaet vårt:

  • Navn
  • E-postadresse
  • Telefonnummer (valgfritt)
  • Meldingsinnhold

3. Formål og rettslig grunnlag

Opplysningene brukes utelukkende for å besvare din henvendelse og eventuelt gi deg et tilbud. Rettslig grunnlag er samtykke (GDPR art. 6 nr. 1 bokstav a) som du gir ved å sende inn skjemaet.

4. Informasjonskapsler (cookies)

Denne nettsiden bruker Google Ads konverteringssporing og Google Analytics. Disse tjenestene kan sette informasjonskapsler i nettleseren din for å måle annonseytelse og besøksstatistikk. Du kan blokkere informasjonskapsler i nettleserinnstillingene dine.

5. Deling med tredjeparter

Vi deler ikke personopplysninger med tredjeparter, bortsett fra:

  • Google — for annonse- og analysemåling (anonymisert)
  • GitHub Pages — nettsiden hostes hos GitHub (Microsoft)

6. Lagring og sletting

Kontaktskjema-data lagres så lenge det er nødvendig for å følge opp henvendelsen, normalt inntil 12 måneder. Du kan når som helst be om sletting.

7. Dine rettigheter

Du har rett til innsyn, retting, sletting og dataportabilitet. Du kan også klage til Datatilsynet. Kontakt oss på e-postadressen over for å utøve dine rettigheter.
